# Recursos d'informàtica

Tot el material dels mòduls en un sol lloc: apunts, pràctiques, activitats i fitxers per descarregar, organitzats per **cicle**, **mòdul** i **resultat d'aprenentatge (RA)**.

<!-- llistat-cicles -->

## Com trobar el que busques

<div class="grid" markdown>

!!! tip "Per mòdul"

    Tria el teu cicle a la barra superior i entra al mòdul. Cada RA té la seva pàgina amb els criteris d'avaluació i tot el material associat.

!!! tip "Per temàtica"

    Si busques un tema concret (DNS, Linux, ciberseguretat…), consulta les [temàtiques](temes.md): agrupa el material de tots els mòduls.

!!! tip "Amb el cercador"

    Prem ++s++ o ++slash++ en qualsevol pàgina per obrir el cercador i escriu el que busques.

!!! tip "Material protegit"

    Les pàgines amb :material-lock-outline: (com les solucions) demanen una contrasenya. El professor te la donarà quan toqui.

</div>
