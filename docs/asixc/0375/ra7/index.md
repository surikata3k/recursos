# RA7 · Serveis d'àudio

!!! abstract "Resultat d'aprenentatge 7"

    Administra serveis d'àudio identificant-ne les necessitats de distribució i adaptant els formats.

??? info "Criteris d'avaluació"

    1. Descriu la funcionalitat del servei d'àudio.
    2. Instal·la i configura un servidor de distribució d'àudio.
    3. Instal·la i configura el client per a l'accés al servidor d'àudio.
    4. Reconeix i utilitza formats d'àudio digital.
    5. Utilitza eines de reproducció d'àudio al client.
    6. Utilitza serveis d'àudio a través del navegador.
    7. Utilitza tècniques de sindicació i subscripció d'àudio.
    8. Elabora documentació relativa a la instal·lació i administració del servidor d'àudio.
