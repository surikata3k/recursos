# RA3 · Servidors web

!!! abstract "Resultat d'aprenentatge 3"

    Administra servidors web aplicant criteris de configuració i assegurant el funcionament del servei.

??? info "Criteris d'avaluació"

    1. Descriu els fonaments i protocols en els quals es basa el funcionament d'un servidor web.
    2. Instal·la i configura servidors web.
    3. Amplia la funcionalitat del servidor mitjançant l'activació i configuració de mòduls.
    4. Crea i configura llocs web virtuals.
    5. Configura els mecanismes d'autenticació i control d'accés del servidor.
    6. Obté i instal·la certificats digitals.
    7. Estableix mecanismes per assegurar les comunicacions entre el client i el servidor.
    8. Realitza proves de monitoratge del servei.
    9. Analitza els registres del servei per a l'elaboració d'estadístiques i la resolució d'incidències.
    10. Elabora documentació relativa a la instal·lació, configuració i recomanacions d'ús del servei.
