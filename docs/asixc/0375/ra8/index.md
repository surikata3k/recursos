# RA8 · Serveis de vídeo

!!! abstract "Resultat d'aprenentatge 8"

    Administra serveis de vídeo identificant-ne les necessitats de distribució i adaptant els formats.

??? info "Criteris d'avaluació"

    1. Descriu la funcionalitat dels servidors de vídeo.
    2. Instal·la i configura un servidor de vídeo.
    3. Configura el client per a l'accés al servidor de vídeo.
    4. Reconeix i utilitza formats de compressió de vídeo digital.
    5. Utilitza tècniques de sindicació i subscripció de vídeo.
    6. Descriu les característiques i els protocols utilitzats en el servei de videoconferència.
    7. Instal·la i configura eines gràfiques per fer videoconferències.
    8. Utilitza eines gràfiques i navegadors per fer videoconferències.
    9. Elabora documentació relativa a la instal·lació i administració dels servidors de vídeo i del servei de videoconferència.
