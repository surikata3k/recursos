# RA2 · Configuració automàtica (DHCP)

!!! abstract "Resultat d'aprenentatge 2"

    Administra serveis de configuració automàtica, identificant-los i verificant la correcta assignació dels paràmetres.

??? info "Criteris d'avaluació"

    1. Reconeix els mecanismes automatitzats de configuració dels paràmetres de xarxa i els avantatges que proporcionen.
    2. Il·lustra els procediments i les pautes que intervenen en una sol·licitud de configuració dels paràmetres de xarxa.
    3. Instal·la servidors de configuració dels paràmetres de xarxa.
    4. Prepara el servei per assignar la configuració bàsica als equips d'una xarxa local.
    5. Configura assignacions estàtiques i dinàmiques.
    6. Integra en el servei opcions addicionals de configuració.
    7. Documenta els procediments realitzats.
