# RA1 · Implantació de l'SGBD

!!! abstract "Resultat d'aprenentatge 1"

    Implanta sistemes gestors de bases de dades analitzant les característiques i ajustant-se als requeriments del sistema.

??? info "Criteris d'avaluació"

    1. Reconeix la utilitat i funció de cadascun dels elements d'un sistema gestor de bases de dades.
    2. Analitza les característiques dels principals sistemes gestors de bases de dades.
    3. Selecciona el sistema gestor de bases de dades.
    4. Identifica el programari necessari per dur a terme la instal·lació.
    5. Verifica el compliment dels requisits de maquinari.
    6. Instal·la sistemes gestors de bases de dades.
    7. Documenta el procés d'instal·lació.
    8. Interpreta la informació subministrada pels missatges d'error i fitxers de registre.
    9. Soluciona les incidències de la instal·lació.
    10. Verifica el funcionament del sistema gestor de bases de dades.
