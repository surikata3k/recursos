# RA3 · Control d'accés

!!! abstract "Resultat d'aprenentatge 3"

    Implanta mètodes de control d'accés utilitzant assistents, eines gràfiques i comandes del llenguatge del sistema gestor.

??? info "Criteris d'avaluació"

    1. Crea vistes personalitzades per a cada tipus d'usuari.
    2. Crea sinònims de taules i vistes.
    3. Defineix i elimina comptes d'usuari.
    4. Identifica els privilegis sobre la base de dades i els seus elements.
    5. Agrupa i desagrupa privilegis.
    6. Assigna i elimina privilegis a usuaris.
    7. Assigna i elimina grups de privilegis a usuaris.
    8. Garanteix el compliment dels requisits de seguretat.
