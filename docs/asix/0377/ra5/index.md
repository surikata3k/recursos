# RA5 · Monitoratge i rendiment

!!! abstract "Resultat d'aprenentatge 5"

    Optimitza el rendiment del sistema aplicant tècniques de monitoratge i realitzant adaptacions.

??? info "Criteris d'avaluació"

    1. Identifica les eines de monitoratge disponibles per al sistema gestor.
    2. Descriu els avantatges i inconvenients de la creació d'índexs.
    3. Crea índexs en taules i vistes.
    4. Optimitza l'estructura de la base de dades.
    5. Optimitza els recursos del sistema gestor.
    6. Obté informació sobre el rendiment de les consultes per optimitzar-les.
    7. Desenvolupa alertes de rendiment.
    8. Realitza modificacions en la configuració del sistema operatiu per millorar el rendiment del gestor.
