# RA6 · Disponibilitat i replicació

!!! abstract "Resultat d'aprenentatge 6"

    Aplica criteris de disponibilitat analitzant-los i ajustant la configuració del sistema gestor.

??? info "Criteris d'avaluació"

    1. Reconeix la utilitat de les bases de dades distribuïdes.
    2. Descriu les diferents polítiques de fragmentació de la informació.
    3. Implanta una base de dades distribuïda homogènia.
    4. Crea una base de dades distribuïda mitjançant la integració d'un conjunt de bases de dades preexistents.
    5. Configura un node mestre i d'altres esclaus, per replicar el primer.
    6. Configura un sistema de replicació en cadena.
    7. Comprova l'efecte de l'aturada de diversos nodes sobre el sistema distribuït i replicat.
