# RA2 · Configuració de l'SGBD

!!! abstract "Resultat d'aprenentatge 2"

    Configura el sistema gestor de bases de dades interpretant-ne les especificacions tècniques i els requisits d'explotació.

??? info "Criteris d'avaluació"

    1. Descriu les condicions d'inici i d'aturada del sistema gestor de bases de dades.
    2. Selecciona el motor de base de dades.
    3. Assegura els comptes d'administració.
    4. Configura les eines i el programari client del sistema gestor.
    5. Configura la connectivitat en xarxa del sistema gestor.
    6. Defineix les característiques per defecte de la base de dades.
    7. Defineix els paràmetres relatius a les connexions: temps d'espera, nombre màxim de connexions, entre d'altres.
    8. Documenta el procés de configuració.
