# RA4 · Automatització de tasques

!!! abstract "Resultat d'aprenentatge 4"

    Automatitza tasques d'administració del gestor descrivint-les i utilitzant guions de sentències.

??? info "Criteris d'avaluació"

    1. Reconeix la importància d'automatitzar tasques administratives.
    2. Descriu els diferents mètodes d'execució de guions.
    3. Identifica les eines disponibles per redactar guions.
    4. Defineix i utilitza guions per automatitzar tasques.
    5. Identifica els esdeveniments susceptibles d'activar disparadors.
    6. Defineix disparadors.
    7. Utilitza estructures de control de flux.
    8. Adopta mesures per mantenir la integritat i consistència de la informació.
