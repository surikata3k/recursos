# RA3 · Criteris de sostenibilitat

!!! abstract "Resultat d'aprenentatge 3"

    Estableix l'aplicació de criteris de sostenibilitat en l'acompliment professional i personal, identificant els elements necessaris.

??? info "Criteris d'avaluació"

    1. Identifica els ODS més rellevants per a l'activitat professional que realitza.
    2. Analitza els riscos i oportunitats que representen els ODS.
    3. Identifica les accions necessàries per atendre alguns dels reptes ambientals i socials des de l'activitat professional i l'entorn personal.
