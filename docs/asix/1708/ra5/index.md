# RA5 · Activitats sostenibles

!!! abstract "Resultat d'aprenentatge 5"

    Realitza activitats sostenibles minimitzant l'impacte de les mateixes en el medi ambient.

??? info "Criteris d'avaluació"

    1. Caracteritza el model de producció i consum actual.
    2. Identifica els principis de l'economia verda i circular.
    3. Contrasta els beneficis de l'economia verda i circular enfront del model clàssic de producció.
    4. Avalua l'impacte de les activitats personals i professionals.
    5. Aplica principis d'ecodisseny.
    6. Aplica estratègies sostenibles.
    7. Analitza el cicle de vida del producte.
    8. Identifica els processos de producció i els criteris de sostenibilitat aplicats.
    9. Aplica la normativa ambiental.
