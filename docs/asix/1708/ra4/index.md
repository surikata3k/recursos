# RA4 · Productes i serveis responsables

!!! abstract "Resultat d'aprenentatge 4"

    Proposa productes i serveis responsables tenint en compte els principis de l'economia circular.

??? info "Criteris d'avaluació"

    1. Caracteritza el model de producció i consum actual.
    2. Identifica els principis de l'economia verda i circular.
    3. Contrasta els beneficis de l'economia verda i circular enfront del model clàssic de producció.
    4. Aplica principis d'ecodisseny.
    5. Analitza el cicle de vida del producte.
    6. Identifica els processos de producció i els criteris de sostenibilitat aplicats.
