# RA3 · Gestió d'arxius web

!!! abstract "Resultat d'aprenentatge 3"

    Instal·la serveis de gestió d'arxius web, identificant-ne les aplicacions i verificant-ne la integritat.

??? info "Criteris d'avaluació"

    1. Estableix la utilitat d'un servei de gestió d'arxius web.
    2. Descriu diferents aplicacions de gestió d'arxius web.
    3. Instal·la i adapta una eina de gestió d'arxius web.
    4. Crea i classifica comptes d'usuari en funció dels seus permisos.
    5. Gestiona arxius i directoris.
    6. Utilitza arxius d'informació addicional.
    7. Aplica criteris d'indexació sobre els arxius i directoris.
    8. Comprova la seguretat del gestor d'arxius.
